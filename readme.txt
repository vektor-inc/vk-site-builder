サイト制作に使うブロックパターンをまとめたプラグインです。

== Description ==

ヒーロー・お問い合わせへの誘導・よくある質問・料金などのセクションを、ブロックパターンとして追加します。
ブロックエディタのパターンの一覧から選んで、ページに挿入できます。
